# Custom Soundboard

Flutter-App mit automatischem GitHub-Actions-Build für Android.

## Enthalten

- Sound-Buttons
- lokale Audiodateien importieren
- mehrere Sounds parallel abspielen
- Loop pro Sound
- Lautstärke pro Sound
- Farbe pro Sound
- lokale Speicherung
- GitHub Actions Workflow für APK-Build

## Wichtig für GitHub

Die Workflow-Datei liegt hier:

.github/workflows/android-apk.yml

Falls dein Gerät den versteckten Ordner .github nicht anzeigt, lege die Datei in GitHub manuell an.
Der gleiche Inhalt liegt zusätzlich sichtbar in:

ANDROID_WORKFLOW_ZUM_KOPIEREN.yml
